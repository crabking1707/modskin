Dò dictionary ZSTD của game

Trang này chạy hoàn toàn trên máy bạn, không gửi file đi đâu. Nó tìm dãy byte 37 A4 30 EC E7 55 43 0B (đầu file dictionary) trong file bạn chọn, rồi lưu một đoạn quanh đó để gửi cho mình.

Bước 1: trong Filza, sao chép file UnityFramework (240,9 MB, nằm trong kgvn.app → Frameworks → UnityFramework.framework) vào ứng dụng Tệp. Có thể chọn thêm các file lớn khác trong thư mục Data của kgvn.app nếu có.

Bước 2: bấm nút bên dưới, chọn file đó.
